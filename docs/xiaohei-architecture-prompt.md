# 小黑怪诞风格 - 系统架构配图 prompt

This session has no image-generation model, so the prompt below is written but not
rendered. Paste it into an image model (GPT-Image-2, Gemini, or similar) to get the
picture. One image; the whole receiver chain as a single absurd machine.

## 配图策略 (shot list)

| | |
|---|---|
| 主题 | RF 信号情报系统架构：一段乱七八糟的电波，被拆解成能读懂的一句话 |
| 结构类型 | 流程隐喻（单条主线，从左到右） |
| 核心意思 | 收到的只是一团乱波；系统一步步量、认、拆、纠，最后吐出人能读的报文 |
| 小黑动作 | 小黑站在一台手摇长机器中间，一手摇柄、一手把乱波塞进漏斗，认真但荒诞 |
| 标注词 | 一团乱波 / 量一量 / 这是什么调制 / 把打乱的顺序拼回去 / 纠错 / 读出来了 |

## 单张生成 prompt（直接复制）

```
16:9 横版中文正文配图，纯白背景，黑色手绘线稿，笔触细、略微抖动、有手绘感，禁止矢量感和机械感。大量留白，主体占画面 40%–60%，右上留一块安静的空白区。

画面内容：画面左边是一团缠成乱麻的电波线（黑色，乱线团状，线头飘出来）。乱波被吸进一个漏斗里。漏斗连着一台横贯画面的手摇长机器，机器由 4 个歪歪扭扭的手绘方盒子串起来，盒子之间用黑色细管连接。

小黑（黑色实心小怪物，白点眼睛，细腿细手，表情空白呆滞但很认真）站在机器正中间，一只手用力摇动机器侧面的大摇柄，另一只手把乱波线头往漏斗里塞——小黑是画面的核心动作主体，不是站在旁边看。

四个盒子里各有一个简单的手绘小图示，不要写盒子标题：
第一个盒子里是一把尺子量着一条波形；
第二个盒子里是几个散点聚成两团（像星座图）；
第三个盒子里是一个被打乱的小方格网格，其中几格正被一只从盒子里伸出的小黑手掰回原位；
第四个盒子里是一串珠子，其中一颗歪的珠子正被扶正。

机器最右端的出口，吐出一张窄长的手绘纸条，纸条上用黑色手写字写着「你好」两个字，纸条微微卷曲垂下来。

手写中文批注（手写体，位置分散，不要框、不要标题栏）：
左边乱波旁边写「一团乱波」（黑色）；
第一个盒子下面写「量一量」（蓝色）；
第二个盒子下面写「这是什么调制」（蓝色）；
第三个盒子上面写「把打乱的顺序拼回去」（橙色）；
第四个盒子下面写「纠错」（橙色）；
右边纸条旁边写「读出来了」（红色）。

橙色只用于机器主流向的一两个小箭头，红色只用于最后「读出来了」，蓝色只用于前两处说明，其余全部黑色。

禁止：PPT 风、商业插画、信息图、正式流程图、课件、可爱卡通、幼稚画风、复杂架构图、UI 截图、彩色背景、阴影渐变、画面左上角的类型标题、超过 6 个批注。整张图只讲一件事：小黑摇着这台机器，把乱波变成一句能读的话。
```

## 生成后自查

- 小黑是否在做核心动作（摇柄 + 塞乱波），而不是站在角落当装饰
- 背景是否纯白，画面是否留够 35% 空白
- 批注是否 ≤ 6 条、是否有多余标题
- 是否看起来像怪诞产品草图，而不是流程图或课件

若不合格：减元素、去标题、把小黑放回动作中心，重新生成。

## 如果需要英文标注（SIH 提交用）

把批注换成：tangled signal / measure it / which modulation / unshuffle the bits /
fix the errors / message out。其余不变。注意这会偏离本 skill 的中文正文配图设定。
